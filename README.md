## Explicação do sistema

O sistema permite cadastrar solicitações técnicas de colaboradores.
Os dados são enviados para uma API REST em Node.js e armazenados no banco MySQL.

## Como executar o projeto

### Backend

Entrar na pasta backend:

npm install

node server.js

### Frontend

Abrir o arquivo index.html
